pre.dev builds software and exposes the pieces behind it as APIs.

| Product | What it does | Start with |
| --- | --- | --- |
| Coding Agent | Builds, verifies, and publishes apps, in the web workspace or your terminal | [Build your first project](/coding-agent/quickstart) |
| Architect | Turns a description into a specification with milestones, stories, and architecture | [Generate a spec](/architect-agent/quickstart) |
| Browser Agents | Runs tasks on websites and returns structured data | [Run a browser task](/browser-agents/quickstart) |
| AI Gateway | One OpenAI-compatible API for hundreds of models from every major lab, paid with pre.dev credits | [Call a model](/ai-gateway/quickstart) |
| Payments and Authentication | Stripe payments and user sign-in, built into every app you build on pre.dev | [Built into every app](/coding-agent/built-in) |

## Choose your interface

| Work from | Use | Start with |
| --- | --- | --- |
| A browser | The web workspace for code, plans, previews, and publishing | [Build your first project](/coding-agent/quickstart) |
| A local repository | The CLI and your existing Git workflow | [Install the CLI](/cli/overview) |
| Your application | REST at `https://api.pre.dev`, the AI Gateway at `https://api.pre.dev/v1`, or the Node and Python SDKs | [API overview](/api-reference/overview) |
| Another AI assistant | The product MCP server at `https://api.pre.dev/mcp` | [Connect MCP](/architect-agent/mcp-setup) |

The public API covers specifications, browser tasks, and AI model calls. For code implementation, start in the web workspace or CLI.

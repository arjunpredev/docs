## Choose your interface

| Work from | Use | Start with |
| --- | --- | --- |
| A browser | The web workspace for code, plans, and previews | [Build your first project](/coding-agent/quickstart) |
| A local repository | The CLI and your existing Git workflow | [Install the CLI](/cli/overview) |
| Your application | REST or an SDK for specifications and browser tasks | [API overview](/api-reference/overview) |
| Another AI assistant | The product MCP server | [Connect MCP](/architect-agent/mcp-setup) |

The public API exposes planning and browser operations. For code implementation, start in the web workspace or CLI.

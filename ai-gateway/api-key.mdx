Each workspace, a personal account or a team, has one pre.dev API key.

<ApiKeyLocation />

## Send the key

| Header | Example |
| --- | --- |
| `Authorization` (recommended) | `Authorization: Bearer pdk_…` |
| `x-api-key` | `x-api-key: pdk_…` |

```bash
curl --fail-with-body https://api.pre.dev/v1/usage \
  -H "Authorization: Bearer $PREDEV_API_KEY"
```

The OpenAI SDKs send `Authorization: Bearer`; the Anthropic SDK sends `x-api-key`. Both are accepted, so no header configuration is needed beyond `baseURL` and the key.

The same key works for the other pre.dev APIs: [specification generation](/architect-agent/overview), [browser agents](/browser-agents/overview), and [MCP](/architect-agent/mcp-setup). See [authentication](/api-reference/authentication) for the account rules those interfaces apply.

## Rotate

Rotate from the same **Integrations → Built-in** card. The old key stays valid for 15 minutes after rotation, so a running app can pick up the new value without a gap. Update the value in your secret store, then confirm a request with the new key succeeds before the window closes.

## Projects built on pre.dev

Every project built on pre.dev has the workspace key in its sandbox environment automatically:

| Variable | Value |
| --- | --- |
| `PREDEV_API_KEY` | The workspace's key |
| `PREDEV_API_URL` | `https://api.pre.dev` |
| `PREDEV_PROJECT_ID` | The project's id |

Nothing to paste. Read [from a pre.dev app](/ai-gateway/from-a-predev-app) for browser and server code.

## Keep it server-side

The key spends the workspace's credits. Call the gateway from a server, an edge function, or a local development environment, and never ship it to the browser or a mobile bundle. Browser code in an app built on pre.dev calls the app's own `/predev-ai` route instead; see [from a pre.dev app](/ai-gateway/from-a-predev-app).

## Attribute usage to a project

Send `x-predev-project-id: <projectId>` on any gateway call to attribute its usage to one of the workspace's projects. Ids for projects the workspace does not own are ignored. The [usage endpoint](/ai-gateway/api/usage) reports the result.

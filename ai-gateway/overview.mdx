The pre.dev AI Gateway is an OpenAI-compatible API for hundreds of models from every major lab. Point an OpenAI-compatible client at the AI Gateway base URL, send your pre.dev API key, and call any model in the pre.dev catalog by the id listed in [`GET /v1/models`](/ai-gateway/api/models). Calls are paid with pre.dev credits.

## What you send

Model ids are `<author>/<slug>` strings exactly as listed by [`GET /v1/models`](/ai-gateway/api/models), for example `anthropic/claude-sonnet-5`, `deepseek/deepseek-v4.1-flash`, `google/gemini-3.8-flash`, or `openai/gpt-6-luna`. There are no separate pre.dev-specific model names.

The standard chat completion fields (`messages`, `temperature`, `max_tokens`, `stop`, and so on) work as you would expect. The pre.dev AI API also supports these options, described on [fallbacks and advanced options](/ai-gateway/routing-and-fallbacks):

| Field | Purpose |
| --- | --- |
| `models`, `route` | Fallback model list |
| `transforms` | Prompt transforms |
| `reasoning`, `reasoning_effort` | Reasoning controls |
| `plugins` | `web`, `file-parser`, `response-healing`, `context-compression` |
| `web_search_options` | Web search settings |
| `response_format`, `structured_outputs` | JSON and schema-constrained output |
| `tools`, `tool_choice`, `parallel_tool_calls` | Tool calling |
| `prediction`, `verbosity`, `session_id` | Predicted outputs, verbosity, session grouping |
| `stream` | Server-sent event streaming |

## What you get back

Responses use the standard OpenAI-compatible shapes, and the Anthropic Messages shape on `/v1/messages`. Model responses carry a pre.dev generation id (`pdg-…`) and token counts in `usage`. Streaming chat completions end with a chunk that carries `usage`.

## Endpoints

| Method | Path | Reference |
| --- | --- | --- |
| POST | `/v1/chat/completions`, `/v1/completions`, `/v1/responses` | [Chat completions](/ai-gateway/api/chat-completions) |
| POST | `/v1/messages` | [Messages](/ai-gateway/api/messages) |
| POST | `/v1/embeddings`, `/v1/rerank` | [Embeddings and rerank](/ai-gateway/api/embeddings) |
| POST, GET | `/v1/images`, `/v1/videos`, `/v1/videos/{jobId}`, `/v1/videos/{jobId}/content` | [Images and video](/ai-gateway/api/images-and-video) |
| POST | `/v1/audio/speech`, `/v1/audio/transcriptions` | [Audio](/ai-gateway/api/audio) |
| POST, GET, DELETE | `/v1/files`, `/v1/files/{id}`, `/v1/files/{id}/content` | [Files](/ai-gateway/api/files) |
| GET | `/v1/models`, `/v1/models/count`, `/v1/embeddings/models`, `/v1/images/models`, `/v1/videos/models` | [Model catalog](/ai-gateway/api/models) |
| GET | `/v1/usage`, `/v1/generation` | [Usage](/ai-gateway/api/usage) |

Any other `/v1` path returns `404`.

## Response headers

Every inference call returns `x-predev-request-id` (`pdr_…`). Completed non-streaming calls also return `x-predev-credits-charged` and `x-predev-credits-remaining` (omitted when the workspace has no credit limit). Streamed calls carry only the request id; read their charge from [`GET /v1/usage`](/ai-gateway/api/usage#usage-totals) or [`GET /v1/generation`](/ai-gateway/api/usage#one-generation). Send `x-predev-project-id` to attribute usage to one of your projects.

## Billing

Each call is charged in credits from the model's metered usage for that call. The credit price per model is listed on [`GET /v1/models`](/ai-gateway/api/models) under `predev.credits_per_m_input` and `predev.credits_per_m_output`. Catalog reads are free. Details and the free allowance are on [pricing](/coding-agent/plans-and-credits#ai-gateway-calls).

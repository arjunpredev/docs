Gateway errors use the OpenAI error shape with an extra `predev` object. The OpenAI and Anthropic SDKs raise them as their usual typed exceptions.

```json
{
  "error": {
    "message": "This pre.dev workspace has no credits left for AI calls. Top up at https://pre.dev/billing or enable auto-recharge.",
    "type": "insufficient_credits",
    "code": "insufficient_credits",
    "param": null,
    "predev": {
      "credits_remaining": 0,
      "estimated_credits": 1.4,
      "topup_url": "https://pre.dev/billing"
    }
  }
}
```

## Codes

| Code | HTTP | Cause | `predev` fields | Handling |
| --- | --- | --- | --- | --- |
| `invalid_request` | `400` | A speech request without `model` and `input`, or with a model that does not produce audio | `available_models` for a wrong model | Fix the request |
| `missing_id` | `400` | `GET /v1/generation` without `id` | | Send the generation id |
| `missing_api_key` | `401` | No `Authorization` or `x-api-key` header | | Send the key; see [authentication](/api-reference/authentication) |
| `invalid_api_key` | `401` | Key unknown, or rotated more than 15 minutes ago | | Copy the current key from **Integrations → Built-in** |
| `insufficient_credits` | `402` | The balance cannot cover the call; nothing was sent to the model | `credits_remaining`, `estimated_credits`, `topup_url` | Add credits or enable auto-recharge |
| `subscription_required` | `402` | A Free workspace used its 5-credit gateway allowance | `credits_remaining`, `trial_credits_used`, `topup_url` | Subscribe |
| `not_found` | `404` | Unknown path, or a file, job, or generation that belongs to another workspace | | Check the path and id |
| `not_ready` | `404` | The generation's stats are not recorded yet | | Retry in a few seconds |
| `rate_limit_exceeded` | `429` | More than the per-minute request limit (600, or 30 on the Free plan) | `retry_after` | Wait `Retry-After` seconds, then retry |
| `too_many_auth_failures` | `429` | Too many failed key attempts from one address | `retry_after` | Check the key, then retry after a minute |
| `internal_error` | `500` | An unexpected gateway error | | Retry, and quote `x-predev-request-id` if it persists |
| `upstream_unavailable` | `502` | The model did not answer | | Retry with backoff; consider `models` fallbacks |
| `balance_unavailable` | `503` | The balance check could not complete | `retry_after` | Wait `Retry-After` seconds, then retry |

The error `type` follows the OpenAI convention for the status, for example `authentication_error` for `401` and `rate_limit_error` for `429`; for `402` it repeats the code.

### `subscription_required`

```json
{
  "error": {
    "message": "The free trial includes 5 credits of AI calls and this workspace has used them. Subscribe at https://pre.dev/billing to keep going.",
    "type": "subscription_required",
    "code": "subscription_required",
    "param": null,
    "predev": {
      "credits_remaining": 18,
      "trial_credits_used": 5,
      "topup_url": "https://pre.dev/billing"
    }
  }
}
```

### `rate_limit_exceeded`

```json
{
  "error": {
    "message": "Rate limit of 600 requests per minute exceeded for this workspace.",
    "type": "rate_limit_error",
    "code": "rate_limit_exceeded",
    "param": null,
    "predev": { "retry_after": 12 }
  }
}
```

The response also sets `Retry-After`. Catalog reads are not rate-limited.

## Errors from the model

When the model rejects a request, for example an unknown model id, a malformed request, or an unsupported parameter, the error keeps its HTTP status and its message about the request, in the same OpenAI error shape. Check the model id against [`GET /v1/models`](/ai-gateway/api/models) first.

## Handling in the SDKs

The OpenAI and Anthropic SDKs raise their usual typed exceptions by status: `AuthenticationError` (401), `RateLimitError` (429), `NotFoundError` (404), and `APIStatusError` with the original `status` for 402, 502, and 503. Read `error.code` from the body to tell `insufficient_credits` from `subscription_required`, and `x-predev-request-id` from the response headers when reporting a problem.

```typescript
import OpenAI from 'openai';

try {
  await client.chat.completions.create({ model: 'anthropic/claude-sonnet-5', messages });
} catch (error) {
  if (error instanceof OpenAI.APIError) {
    const code = (error.error as any)?.code;
    if (code === 'insufficient_credits') redirectTo((error.error as any).predev.topup_url);
    else if (error.status === 429) scheduleRetry(Number(error.headers?.get('retry-after') ?? 5));
    else throw error;
  }
}
```

Streams that fail after headers are sent end early; the charge covers what the model generated. See [streaming](/ai-gateway/streaming).

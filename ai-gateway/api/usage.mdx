## Per-call headers

| Header | Meaning |
| --- | --- |
| `x-predev-request-id` | `pdr_…`, on every inference call; quote it when contacting support |
| `x-predev-credits-charged` | Credits charged for this call, on completed non-streaming calls |
| `x-predev-credits-remaining` | Workspace balance after the call; omitted when the workspace has no credit limit |

Send `x-predev-project-id: <projectId>` on a request to attribute it to one of the workspace's projects. Ids of projects the workspace does not own are ignored.

## Usage totals

`GET /v1/usage` returns totals for the last `days` days (1 to 90, default 30), broken down by model and path. The read is not charged.

```bash
curl --fail-with-body "https://api.pre.dev/v1/usage?days=30" \
  -H "Authorization: Bearer $PREDEV_API_KEY"
```

```json
{
  "workspace": "…",
  "project": null,
  "credits_remaining": 412.5,
  "tier": "SoloPro",
  "since": "2026-08-28T00:00:00.000Z",
  "totals": { "requests": 1840, "credits": 87.5 },
  "by_model": [
    {
      "model": "deepseek/deepseek-v4.1-flash",
      "path": "/chat/completions",
      "requests": 1702,
      "credits": 41.2,
      "prompt_tokens": 9120000,
      "completion_tokens": 1410000,
      "errors": 3
    },
    {
      "model": "anthropic/claude-sonnet-5",
      "path": "/messages",
      "requests": 138,
      "credits": 46.3,
      "prompt_tokens": 610000,
      "completion_tokens": 92000,
      "errors": 0
    }
  ]
}
```

| Field | Meaning |
| --- | --- |
| `workspace` | The workspace the key belongs to |
| `project` | The project named by `x-predev-project-id`, or `null` |
| `credits_remaining` | Current balance; `null` when the workspace has no credit limit |
| `tier` | Plan tier |
| `since` | Start of the window |
| `totals.requests`, `totals.credits` | Window totals |
| `by_model[].model`, `path` | One row per model and endpoint |
| `by_model[].requests`, `credits` | Volume and credits for that row |
| `by_model[].prompt_tokens`, `completion_tokens` | Token totals |
| `by_model[].errors` | Requests that returned an error |

## One generation

[`GET /v1/generation?id=<id>`](/ai-gateway/api/generation) returns the record of one call, using the `pdg-…` id from the response body or a stream chunk. Only this workspace's generations are visible. Stats can take a few seconds to appear after a call; a `404` with code `not_ready` means retry shortly.

```bash
curl --fail-with-body "https://api.pre.dev/v1/generation?id=pdg-7c1e4b52-9a3d-4f8e-b0c6-2d5a8e913f47" \
  -H "Authorization: Bearer $PREDEV_API_KEY"
```

The body's `data` object reports the model, timing (`latency`, `generation_time`), `finish_reason`, whether the call streamed or was cancelled, token counts including reasoning and cached tokens, counts of images and other attachments, and `credits`: the credits charged for the call.

---
title: "Collaboration"
description: "Invite people to a project, share links to the app, and share a read-only overview."
---

Open **Share** in the project header, or type `/share`. The Share dialog has three parts: links to the app, the people who can open the project, and a read-only overview link.

## Links to the app

| Link | What it opens |
| --- | --- |
| Live | The [published](/coding-agent/building/publish) app. It changes only when you publish. |
| Draft | Your latest changes, as Preview shows them. Opening it wakes the sandbox, so it can take a few seconds. |

Both links follow the app's access setting, **Anyone** or **Invited only**, which you set in [Publish](/coding-agent/building/publish#who-can-open-it). Opening the app does not let someone edit the project. Your app's own sign-in and permissions are separate from this setting.

## Invite people

Enter an email and choose **Invite**. People you invite open the project itself.

| Access | Project access |
| --- | --- |
| Owner | Everything, including everyone's access |
| Can edit | Work on the project, publish it, and invite people with **Can view** access |
| Can view | View the project |

The owner chooses **Can view** or **Can edit** for each invitation and can change or remove anyone's access. People with **Can edit** can invite others as **Can view** and remove viewers. **Copy project link** copies a link that only the people listed can open.

## Read-only overview

Turn on **Overview** to share a read-only page with the project's plan, architecture, roadmap, and estimates. Anyone with its link can read it without signing in; it shows no chat or code. It is off by default.

## Work in parallel

Use [separate sessions](/coding-agent/building/sessions-and-parallel-agents) for distinct workstreams. Presence indicators show which session collaborators are viewing. Review each session before merging it into Main; a clean merge can complete automatically.

Team projects use organization-scoped connections and configuration. Review [integration scope](/coding-agent/integrations/overview) before changing a setting shared with other projects.

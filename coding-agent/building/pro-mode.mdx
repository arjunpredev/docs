---
title: "Model selection"
description: "Choose a model for all phases or set different models for each phase."
---

Use `/model` to open the model picker. The live catalog shows the choices available to your account; model availability and defaults can change.

| Phase | Work it controls |
| --- | --- |
| Chat | Conversation and direct agent work |
| Research | Investigation in workflows with a research phase |
| Coding | Implementation in workflows with a coding phase |
| Acceptance | Verification in workflows with an acceptance phase |

Choose one model for all phases or set a phase separately. On the web, `/model all <model>` applies one model throughout, `/model <phase> <model>` sets one phase, and `/model reset` restores automatic choices.

Choosing a model is part of the Premium, Pro, and Team plans; other plans use the automatic choice, and picking a locked model opens Billing. Model settings persist with the project. A phase selection only matters when that phase runs; [effort](/coding-agent/building/build-modes#sprint-effort) determines the sprint workflow.

<Note>
  `/pro` has been retired. Use `/model` for model selection. The **Pro** plan is a billing plan and is separate from these controls.
</Note>

For credits and plans, see [plans, credits, and pricing](/coding-agent/plans-and-credits).

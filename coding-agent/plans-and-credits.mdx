## Plans

| Plan | Monthly | Annual | Credits | Adds |
| --- | --- | --- | --- | --- |
| Free | $0 | $0 | 20 a month | Coding agent in the browser and terminal, browser agents, publishing for 7 days |
| Plus | $10 | $99 | 100 a month | More monthly credits |
| Premium | $49 | $499 | 500 a month | Model selection, published apps that stay live, custom domains |
| Pro | $199 | $1,999 | 2,500 a month | More monthly credits |
| Team | $499 | $4,990 | 5,000 a month, pooled | Unlimited team seats |
| Enterprise | Custom | Custom | Per agreement | A dedicated solutions engineer |

Each plan includes everything in the plans above it. A team workspace without a plan gets its 20 free credits once, not every month. See [pricing](https://pre.dev/pricing) for current offers, and manage your plan, top-ups, and auto-recharge in **Billing**.

## What uses credits

| Work | How it is charged |
| --- | --- |
| Coding and planning | Measured model work; model choice and effort affect usage |
| Verification | Each judge call is charged like a turn |
| Images, video, and audio the agent generates | Charged per generation |
| Fast and Deep specs | Variable; see the [Architect overview](/architect-agent/overview) for estimates |
| Browser tasks | A floor per task at submission, and more for successful tasks that do more work |
| [Browser Agents Local](/browser-agents/local) | A small fraction of a credit per plain-words action; every other Local tool is free |
| AI calls from your apps | Each call at the model's credit price; see [AI Gateway calls](#ai-gateway-calls) |

## AI Gateway calls

Calls to the [AI Gateway](/ai-gateway/overview), including the AI features in apps you build on pre.dev, are charged from each call's metered usage at the model's credit price. The price per model is listed on [`GET /v1/models`](/ai-gateway/api/models): each row carries a `predev` object with `credits_per_m_input` and `credits_per_m_output` and, where the model has them, prices such as `credits_per_m_cache_read`, `credits_per_m_cache_write`, `credits_per_image`, and `credits_per_request`. Read those numbers rather than deriving prices yourself.

Worked example: a model whose row lists `credits_per_m_input: 20` and `credits_per_m_output: 100` costs 0.2 credits for 10,000 input tokens plus 0.2 credits for 2,000 output tokens, so a call of that size settles at about 0.4 credits.

- Plugin costs, such as web search, are part of the call's charge.
- With `models` fallbacks, you pay the price of the model that answered.
- Streams settle when they end. If your client disconnects mid-stream, the call is charged for what the model generated.
- Video jobs are charged when a status poll reports completion, and submitting one needs at least 10 credits available. See [images and video](/ai-gateway/api/images-and-video).
- Catalog reads are free.

Non-streaming responses report the charge in `x-predev-credits-charged` and the balance in `x-predev-credits-remaining`. [`GET /v1/usage`](/ai-gateway/api/usage) breaks the last 1 to 90 days down by model and path.

**Free allowance.** A Free workspace can spend 5 credits on gateway calls in total, whatever its credit balance. After that, every call returns `402` with code `subscription_required` until the workspace subscribes.

**Out of credits.** A workspace without enough credits for a call gets `402` with code `insufficient_credits` before anything is sent to the model, so nothing is generated or charged. Turn on auto-recharge in billing to keep a live app running when the balance would otherwise reach zero. See [AI Gateway errors](/api-reference/errors#ai-gateway-errors).

## Check usage and recover

- `/balance` shows the account balance.
- The credits pill next to the composer shows what the current project has used. Select it for **Credits on this project**: a newest-first ledger of turns with the phase, model, tokens, and credits for each.
- `/usage` in the CLI shows the same breakdown in the terminal.
- In the CLI, `/topup` and `/upgrade` open billing.

A run paused for insufficient credits can pick up where it stopped after you add credits; check its current status before launching duplicate work.

For integrations, [GET /credits-balance](/architect-agent/api/credits-balance) returns the effective balance, and [GET /browser-agent-status](/browser-agents/api/queue-status) reports the current browser in-flight cap.

## API and MCP access

The Architect API and the MCP server are included with the Premium, Pro, Team, and Enterprise plans. Plus accounts, and team workspaces without an active plan, can connect and generate 3 specifications as a trial; after that, generation returns `403`. Free accounts cannot authenticate to the Architect API or MCP.

Browser Agents REST and the AI Gateway accept every account, including Free. See [authentication](/api-reference/authentication) for how each interface checks keys and [errors and retries](/api-reference/errors) for access errors.
